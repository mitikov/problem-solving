# Резервний розбір моделі LOOPY

Використовуйте, якщо LOOPY не відкривається. Цей файл замінює тільки перші чотири хвилини [завдання 4](task-04.md); паспорт і зміну умови виконайте за основною інструкцією.

## Початкова схема

```text
Signal ──(+)──> Response ──(+)──> Emptying ──(−)──> Overflow
```

Signal — інтенсивність повідомлень; Response — дій у відповідь; Emptying — спорожнення; Overflow — вираженість переповнення. Це умовні величини. Усі три стрілки є заданими для вправи причинними припущеннями.

## Правила

1. У всіх вузлів є умовний початковий стан. Розглядаємо тільки напрям його зміни: збільшення, зменшення або відсутність зміни.
2. Один клік угору збільшує Signal і надсилає одну зміну вздовж вихідної стрілки.
3. Знак `+` зберігає напрям зміни, знак `−` змінює його на протилежний. Вузол, який отримав зміну, передає її далі за наявними вихідними стрілками.
4. Якщо стрілки немає, через це місце зміна не передається. Інших шляхів і зовнішніх подій у цій навчальній моделі немає.
5. Перед кожним новим дослідом усі вузли повертаються в початковий стан.

## Ваші дії

- Запишіть прогноз. Простежте одну зміну Signal від початку до кінця. Заповніть перший рядок таблиці із завдання 4, позначивши його «ручний розбір».
- Оберіть один неперевірений вплив і поясніть його зміст для реального процесу. Запишіть прогноз для версії без цього впливу.
- Скопіюйте схему, вилучіть одну стрілку та повторіть розбір від початкового стану. Заповніть другий рядок таблиці.
- Поясніть, яких реальних даних цей розбір не створює. Продовжуйте з паспорта проблеми.
