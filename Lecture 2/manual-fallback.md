# Ручний маршрут без тренажера

Виконуйте ті самі чотири [завдання](readme.md#маршрут), заповнюючи [шаблон звіту](report-template.md). Критерії й час не змінюються. Достатньо текстового редактора та калькулятора. Зазначте «ручний розбір моделі».

## 1. Репліки

Розділіть [R1–R6](scenario.md) на дев’ять фрагментів за крапками у перших трьох репліках. Скопіюйте їх у чотири категорії. Перед підказкою збережіть початкову версію.

<details><summary>Пояснення пастки — відкрити після прогнозу</summary>

Телефон задає канал реалізації. Відкривання без інструмента задає бажану поведінку обслуговування, але не визначає засувку, магніт чи інший механізм. Обидві репліки можуть допомогти вивести потребу; однакове слово «хочу» не робить їх однаковими за змістом. R5 повідомляє про невизначеність стану: потребу у зрозумілому розрізненні станів ви виводите з цього свідчення, а не знаходите готовою цитатою.

</details>

## 2. Час

Зберігайте `p = 0,2 с`. Для D = 1 і D = 5 знайдіть найбільший додатний T, за якого `T+p≤D`. Обчисліть `1/T` та `3600/T`. Для третього досліду залиште T незмінним, змініть фазу від 10 % до 90 % й обчисліть `(1−a)T+p`, де a — фаза, поділена на 100. Порівняйте окремий дослід та гарантію `T+p`.

## 3. Бюджет

Класифікуйте K1–K5. Складіть суму за [каталогом](scenario.md#каталог-для-кошторису). Перевірте три умови: сума ≤ бюджет; T + 0,2 ≤ 5; додаток оброблення непридатних даних увімкнений. Запишіть рішення за 800 і 500 грн. Окремо дослідіть вилучення оброблення помилок. Поясніть компроміс.

## 4. Стенд

Спочатку запишіть очікування для звичайного, граничного та помилкового входу. Лише потім відкрийте спостереження для вибраної моделі. Таблиці нижче — **задані результати синтетичних моделей**, не еталонні відповіді. Порівняйте їх зі специфікацією, самостійно визначте дефект і придатність результату.
