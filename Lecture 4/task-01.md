# 1. Особистий пошук

**Час: 8 хв. Блок 4.1.**

1. Не відкриваючи карток аналогій, запишіть три власні ідеї індикатора. Для кожної: вхідна подія, механізм, видимий результат для людини.
2. Збережіть початкову версію. Передбачте, яка спільна заборона найбільше змінить ваш напрям.
3. Відкрийте картку нижче та створіть четверту ідею. Позначте змінене припущення.
4. Згрупуйте чотири варіанти за принципом дії. Колір або нова назва самі по собі не утворюють нового принципу.

<details><summary>Нова умова — відкрийте після трьох ідей</summary>

Електроніку заборонено: датчик, контролер і електричний індикатор у четвертому варіанті недоступні. Які ресурси залишаються? Не переписуйте перші три ідеї.

</details>

**Здати:** чотири записи, пояснення зміни, одна неперевірена властивість. **Самоперевірка:** механізм пояснює зв’язок між станом контейнера та повідомленням.

<details><summary>Підказка 1</summary>Опишіть спочатку функцію без назв деталей.</details>
<details><summary>Підказка 2</summary>Подумайте, чи вже є рух, сила або видимий стан, який можна використати.</details>
