# Лабораторна №4. Чотири способи зрушити думку

До лекції «Ідеї без очікування натхнення». Індивідуальна робота на **45 хв** без обладнання, платних сервісів і обов’язкового використання ШІ.

## Маршрут

| Час | Етап |
| --- | --- |
| 0–3 | Прочитайте [сценарій](scenario.md), скопіюйте [звіт](report-template.md) |
| 3–11 | [А. Особистий пошук](task-01.md) |
| 11–21 | [Б. Контрольні питання](task-02.md) |
| 21–31 | [В. Аналогія під навантаженням](task-03.md) |
| 31–43 | [Г. Швидкість проти енергії](task-04.md) |
| 43–45 | Перевірте й збережіть звіт |

Перші три ідеї запишіть **до відкривання карток**. Початкові версії й прогнози не стирайте. Працюйте за порядком: прогноз, зміна умови, спостереження, пояснення.

## Інструменти

[Картки](cards.md) відкриваються прямо в GitHub. [Калькулятор режимів](lab.html) завантажте через Download raw file і відкрийте локально браузером: GitHub показує код HTML. Калькулятор не звертається до мережі та не зберігає звіт. Записи ведіть у власній копії шаблону. Кнопка експорту завантажує лише поточний розрахунок.

Резерв: [model.py](model.py) у Python 3 без бібліотек або ручний розрахунок за формулами [сценарію](scenario.md). Картки й дані повністю містяться в папці. Інтернет після завантаження не потрібний.

## Що здати

Один заповнений звіт: початкові ідеї, три перетворення, аналогія й межа, сформульована суперечність, прогноз та результати зміни режимів, портфель **шести ідей щонайменше з трьома принципами дії**. Кожна ідея має метод походження, користь, невідоме та наступний тест. Скриншоти не потрібні.

Оцінювання: 2 бали за застосування методів, 1 за зміну умов із прогнозом, 1 за перевірку моделі та її меж, 1 за обґрунтований портфель і висновок. Ручний або Python-шлях рівноцінні. 45 хв — плановий час, не результат випробування на групі.
