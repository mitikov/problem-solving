# Картки для етапів Б і В

Не відкривайте до завершення перших трьох власних ідей.

## SCAMPER: виберіть три різні номери

1. **Замінити.** Який елемент або ресурс можна замінити іншим?
2. **Поєднати.** Які дві функції може виконувати той самий елемент?
3. **Адаптувати.** Який відомий спосіб роботи можна пристосувати до іншого середовища?
4. **Змінити.** Що дасть зміна розміру, форми або масштабу сигналу?
5. **Використати інакше.** Яку нову функцію може виконувати наявний рух або поверхня?
6. **Усунути.** Яку деталь чи дію можна прибрати? Хто виконає її функцію?
7. **Переставити / обернути.** Що зміниться при іншому розташуванні, порядку чи напрямі дії?

## Аналоги

- **Поплавок:** рівень рідини змінює положення тіла.
- **Поштова скринька з прапорцем:** видимий стан зберігає повідомлення після події.
- **Світлофор:** обмежений набір сигналів кодує стани.

<details><summary>Несприятлива умова для поплавка</summary>У контейнері сухі нерівномірні відходи, можливе заклинювання рухомого елемента.</details>
<details><summary>Несприятлива умова для прапорця</summary>Контейнер спорожнили, але ніхто вручну не повернув покажчик у початковий стан.</details>
<details><summary>Несприятлива умова для світлофора</summary>Користувач не розрізняє обрані кольори. Чи є друга ознака стану?</details>

## Фокальні об’єкти

Виберіть один випадково: парасоля — складна; губка — пориста; блискавка на одязі — рознімна. Перенесіть властивість на індикатор та поясніть технічний зміст. Саме слово не є концепцією.
