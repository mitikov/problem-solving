# Python: зміна умов моделі

Основна модель готова в `model.py`, щоб програмування не завадило досліду. Після основної роботи:

1. Додайте випадковий вибір трьох різних карток зі списку семи через `random.sample`. Запишіть вибрані номери, щоб дослід можна було відтворити.
2. Сформуйте список результатів для p від 0 до 1 із кроком 0,1. Критерій: при p = 1 кількість вимірювань обох режимів однакова; при p = 0 адаптивний режим використовує low.
3. Додайте витрати сну P_sleep × T у тих самих одиницях. Поясніть, чому відсоток економії всього пристрою зміниться. Не підставляйте паспортні дані навмання.

Готових висновків та ідей не надано. Перевірка формули не замінює перевірки моделі пристрою.
